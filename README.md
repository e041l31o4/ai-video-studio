# AI VIDEO STUDIO

Browser-first short-video editing workspace.

## Run locally

- Node.js 20+
- `npm install`
- `npm run dev`
- `npm run build`

## MVP

Responsive editor, local media import, preview, clip ordering/trimming and FFmpeg.wasm MP4 export. AI transcription, AI voice, generative media, cloud rendering, accounts and billing are planned follow-up modules, not yet implemented.

4K and long-form processing depend on the user's device memory, browser support and source media. Initial processing runs locally; there is no hosted rendering backend.
